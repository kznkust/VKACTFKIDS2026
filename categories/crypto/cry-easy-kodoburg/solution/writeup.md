# Kodoburg

| Событие | Название | Категория | Сложность |
| :-----: | :------: | :-------: | :-------: |
| VKACTF Kids 2026 | Kodoburg | Crypto | Easy |

  
### Описание

>
Головолмка с шифрами древности

### Решение

## Станция I. Ворота: шифр Цезаря

1. Берём первые буквы шифра и сдвигаем назад на 0, 1, 2, …
2. При сдвиге 16 первые 6 букв `ТЮАЮВР` превращаются в `ВОРОТА`. Остальные сдвиги дают мусор (`СЭЯЭБП`, `РЬЮЬАО`, …).
3. Применяем сдвиг 16 ко всему свитку:

```
ТЮАЮВРЮВЪАЛВЛЪЫОЗЪСРИЭХЗХАВЮУ  →  ВОРОТА ОТКРЫТЫ КЛЮЧ К БАШНЕ ЧЕРТОГ
```

**Ответ станции: `ЧЕРТОГ`** 

## Станция II. Башня: шифр Виженера

Подписываем ключ под шифром, повторяя по кругу, и вычитаем по буквам (проще всего по таблице рун: в строке буквы ключа находим букву шифра и поднимаемся вверх):

```
шифр:  Ж К З Т А Я Ш …
ключ:  Ч Е Р Т О Г Ч …
текст: П Е Ч А Т Ь Б …
```

Первая буква: Ж=6, Ч=23, 6−23 = −17 ≡ 15 (mod 32), это П. Вторая: К=10, Е=5, 10−5 = 5, это Е. Так получается весь текст:

```
ПЕЧАТЬ БАШНИ СИРЕНА ОТКРОЕТ РЕШЕТКУ
```

**Ответ станции: `СИРЕНА`** 

## Станция III. Сундук: поворотная решётка
Для примера (решётка 6×6, по 9 окошек в положении):
| Положение | Прочитанные символы |
|---|---|
| 1 | `v k a { g r 1 l l` |
| 2 | `3 _ 0 f _ k 0 d 0` |
| 3 | `b u r g } l _ 5 q` |
| 4 | `l n u 8 w w a 7 u` |

Склеиваем: `vka{gr1ll3_0f_k0d0burg}l_5qlnu8wwa7u`. Флаг начинается с `vka{` и заканчивается первой `}`, всё после неё это «пыль» (случайные символы, которыми дополнен квадрат).

Решение представленно в [`solution.py`](./solution.py)
