# Дробный нотариус

| Событие | Название | Категория | Сложность |
| :-----: | :------: | :-------: | :-------: |
| VKACTF Kids 2026 | Дробный нотариус | Crypto | Medium |

### Решение

В раздатке находятся модуль RSA, два шифротекста и контейнер с флагом. Сообщения связаны дробно-линейным преобразованием с неизвестным малым параметром. Последовательно используем **результант, метод Копперсмита и полиномиальный НОД**, чтобы восстановить ключ контейнера.

**Увидеть дробно-линейную связь**

`c1=m³ mod n`, `c2=((m+r)/(m+1))³ mod n`, где r — неизвестное 48-битное число.
Здесь нет маленькой приватной экспоненты; обычная атака Винера не является
решением. Целочисленный кубический корень тоже не подходит: m случайно во
всём диапазоне n. Сначала нужно устранить большое неизвестное m.

**Вывести результант без символьного чёрного ящика**

Работаем в кольце `(Z/nZ)[x]/(x³−c1)`. После подстановки x³=c1 второй
полином `(x+r)³−c2*(x+1)³` имеет вид `a+b*x+c*x²`, где

- `a=r³+(1−c2)*c1−c2`;
- `b=3r²−3c2`;
- `c=3r−3c2`.

Определитель умножения на этот элемент равен
`a³+c1*b³+c1²*c³−3*c1*a*b*c`.
Это монический полином f(r) степени 9 с малым корнем по модулю n.

**Найти r методом Копперсмита**

Берём X=2⁴⁸, m=2 и t=9. Строим 27 полиномов:
`n^(m−i)*x^j*f(x)^i` для i=0,1 и j=0..8, затем `x^j*f(x)^m` для j=0..8.
Коэффициент степени k масштабируем X^k и применяем LLL.
У коротких приведённых полиномов r становится целочисленным корнем;
убираем масштаб, берём НОД нескольких соседних полиномов и извлекаем
целые корни. Проверяем диапазон и исходное сравнение f(r)=0 mod n.

**Восстановить m над составным модулем**

Теперь вычисляем полиномиальный НОД `x³−c1` и
`(x+r)³−c2*(x+1)³` над Z/nZ. В штатном случае он линейный и даёт m.
Кольцо не является полем: если при делении ведущий коэффициент не обратим,
его НОД с n может сразу дать факторизацию. Solver обрабатывает и этот случай.
Проверяем обе исходные RSA-записи, затем открываем box ключом `[m,r]`.

**Запуск решения**

Для запуска нужны Python 3.10+ и `python-flint==0.8.0` из [requirements.txt](requirements.txt). Команда из корня набора:

```sh
python3 06_rational_notary/solution/solve.py
```

Скрипт читает соседний каталог `give`; другой путь к раздатке можно передать первым аргументом. Сервер и интернет во время решения не требуются.

Солв представлен в файле [solve.py](solve.py).
