# Шумный хор

| Событие | Название | Категория | Сложность |
| :-----: | :------: | :-------: | :-------: |
| VKACTF Kids 2026 | Шумный хор | Crypto | Medium |

### Решение

В `data.json` записаны 8192 выходных бита прибора и контейнер с флагом. Для открытия контейнера требуются исходные состояния трёх регистров и периодическая маска. Используем **корреляционную атаку** после устранения маски разностью потока с его сдвигом.

**Почему прямой BM здесь не работает**

Выход — нелинейная majority-комбинация трёх LFSR, XOR с повторяющейся
17-битной маской и 248 инверсий из-за канала. Известного открытого текста
нет. Применение Берлекэмпа–Мэсси к записи не восстановит три исходных регистра.
Перебор всех состояний одновременно имеет пространство около 2⁶⁰.

**Устранить периодическую маску**

Вычисляем `D_t=Y_t XOR Y_(t+17)`. Маска сокращается. Для случайных независимых
битов `majority(a,b,c)` совпадает с a с вероятностью 3/4. Для двух времён
разность majority совпадает с разностью a с вероятностью
`(3/4)²+(1/4)²=5/8`. Ошибки канала уменьшают, но не уничтожают корреляцию.
Это статистическая модель; для конкретной записи измеряем реальный результат.

**Выполнить корреляционный поиск по каждому регистру**

LFSR линеен по начальному состоянию. Генерируем полные выходы для единичных
состояний, применяем разность с лагом 17 и упаковываем каждый результат в
один Python int. По коду Грея следующий кандидат отличается XOR-ом одного
базисного потока. `int.bit_count()` быстро считает расстояние до D.
Перебираются отдельно 2¹⁹, 2²⁰ и 2²¹ состояний, а не их произведение.

Правильный минимум заметно отделён от шума; solver требует расстояние менее
46% и затем проверяет точное число ошибок в исходной, не разностной записи.

**Вернуть маску и проверить состояния**

После восстановления трёх потоков вычитаем majority из Y. В каждом из 17
классов позиций большинство битов даёт соответствующий бит маски. Полная
реконструкция должна отличаться ровно в `8192//33=248` позициях.
Контейнер дополнительно проверяет точные начальные состояния и маску.

**Запуск решения**

Для запуска достаточно Python 3.10+ и стандартной библиотеки. Команда из корня набора:

```sh
python3 04_noisy_choir/solution/solve.py
```

Скрипт читает соседний каталог `give`; другой путь к раздатке можно передать первым аргументом. Сервер и интернет во время решения не требуются.

Солв представлен в файле [solve.py](solve.py).
