# Багаж с переносами

| Событие | Название | Категория | Сложность |
| :-----: | :------: | :-------: | :-------: |
| VKACTF Kids 2026 | Багаж с переносами | Crypto | Medium |

### Решение

В раздатке даны два набора весов и старшие части двух модульных сумм. Они кодируют один 72-битный секрет, но во второй сумме неизвестно циклическое выравнивание битов. Строим **совместную решётку для двух усечённых сумм**, учитывающую переполнения и неизвестные младшие биты.

**Восстановить модель с переносами и ошибками усечения**

Неизвестны 72 двоичных переменных, две величины переполнения, два остатка
младших 40 бит и фаза второго счётчика. Для фиксированной фазы получаем
два равенства `sum(w_ji*b_i)−q_j*p = head_j*W + e_j`, где
`0≤e_j<W=2^40`. Простой meet-in-the-middle потребовал бы таблицу около 2³⁶
элементов, а точная subset-sum атака не учитывает отсутствующие младшие биты.

**Построить совместную embedding-решётку**

Выбираем центры `t_j=head_j*W+W/2` и базис размерности 75:

- 72 строки `(2W*e_i, 2w_0i, 2w_1i, 0)`;
- две строки с `2p` в соответствующей координате суммы;
- embedding-строка `(W,...,W,2t_0,2t_1,W)`.

Из последней строки вычтем строки выбранных предметов и добавим строки
переполнения. Первые 72 координаты станут ровно ±W, два остатка по модулю
будут по абсолютной величине не более W, а последняя координата равна W.
Именно это делает искомый вектор коротким. Масштабирование обязательно:
без него базис ориентируется на малые единичные координаты, а не на ошибки.

**Найти выравнивание и двоичный вектор**

Для каждой из 18 фаз переиндексируем второй набор коэффициентов и запускаем
LLL. Отбираем только векторы с последней координатой ±W и всеми первыми
координатами ±W. Знак embedding нормализует ориентацию; получаем
`b_i=(1−v_i/W)/2`. Проверяем обе усечённые суммы в исходной схеме и MAC.

LLL — эвристический инструмент для этой задачи, а не универсальный solver
рюкзака. Фиксированный экземпляр проверен; для произвольного seed может
понадобиться BKZ или иная embedding-константа. Само наличие короткого
вектора не означает, что любое LLL-приведение обязано его вернуть.

**Запуск решения**

Для запуска нужны Python 3.10+ и `python-flint==0.8.0` из [requirements.txt](requirements.txt). Команда из корня набора:

```sh
python3 05_carry_baggage/solution/solve.py
```

Скрипт читает соседний каталог `give`; другой путь к раздатке можно передать первым аргументом. Сервер и интернет во время решения не требуются.

Солв представлен в файле [solve.py](solve.py).
