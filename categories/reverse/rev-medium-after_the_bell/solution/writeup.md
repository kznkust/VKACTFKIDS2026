# После звонка

| Событие | Название | Категория | Сложность |
| :-----: | :------: | :-------: | :-------: |
| VKACTF Kids 2026 | После звонка | Reverse | Medium |

**Восстановление маршрута по снимкам состояния**

### Описание

Восстановите забытую надпись дирижёра по записи последней репетиции.

### Решение

Получаем Linux x86-64 программу [bell](../give/bell) и запись [auditorium.rpl](../give/auditorium.rpl). По `bell --help` видим интерфейс `[flag [asset_file]]`. Без второго аргумента программа ищет запись рядом с исполняемым файлом.

Разбираем выданный ELF через REA с GNU objdump. По адресу `0x1328` программа проверяет сигнатуру `ECHO`. В районе `0x151a–0x1587` раскрываются контрольные снимки, а `0x15a2–0x1667` — цикл обработки жестов. В `0x166d–0x16a3` сравниваются все поля состояния. Адреса указаны до смещения ASLR.

Первые 20 байтов файла разбираются форматом `<4sBBHII4B`:

| Смещение | Размер | Значение в выдаче |
| :--- | :--- | :--- |
| `0x00` | 4 | Сигнатура `ECHO` |
| `0x04` | 1 | Версия `2` |
| `0x05` | 1 | Число блоков: `5` |
| `0x06` | 2 | Число жестов на блок: `8` |
| `0x08` | 4 | Seed доски: `1780805769` |
| `0x0c` | 4 | Начальный накопитель `a`: `1461818331` |
| `0x10` | 4 | Байты `x=2, y=6, f=1, e=145` |

Далее идут 64 зашифрованные клетки доски и пять восьмибайтовых снимков. Общая длина текущего файла — `84 + 5*8 = 124` байта.

Для расшифровки используется xorshift32:

```python
def xs(x):
    x ^= (x << 13) & 0xffffffff
    x ^= x >> 17
    return (x ^ (x << 5)) & 0xffffffff

board = []
for i in range(64):
    seed = xs(seed)
    board.append(data[20 + ((17*i + 9) & 63)] ^ (seed & 255))
```

Получаем поле `8×8` со значениями `0..15`. Наивный поиск пути только по координатам здесь не подходит: полное состояние состоит из `(x, y, f, e, a)`, где `f` — направление, `e` — байтовое эхо, `a` — 32-битный накопитель.

Ввод преобразуется в жесты: каждый байт внутри `vka{...}` читается парами бит от старших к младшим. Значениям `0,1,2,3` сопоставим `w,a,s,d`. Это обозначения команд; перемещение зависит также от направления и эха. Десять символов тела флага превращаются в 40 жестов.

Восстановленный переход для команды `c` на шаге `t` выглядит так. `rol` выполняет циклическое вращение в указанной разрядности:

```python
MASK = 0xffffffff

def step(state, c, t, board):
    x, y, f, e, a = state
    f = (f + (0, 3, 2, 1)[c] + (e >> 7)) & 3
    x = (x + (0, 1, 0, -1)[f]) & 7
    y = (y + (-1, 0, 1, 0)[f]) & 7
    bell = rol((board[8*y+x]*13) ^ (x*17+y*29)
               ^ ((t*7) & 255), f+1, 8)
    a = (rol(a ^ (((e+0x9d)*0x01010101) & MASK), 5)
         + bell*0x045d9f3b + (c+1)*0x9e3779b1) & MASK
    e = (bell ^ (e >> 1) ^ (c*41)) & 255
    return x, y, f, e, a
```

Вычисление накопителя использует старое `e`, а координаты и звонок — уже обновлённое направление. Такой порядок существенен для совпадения с бинарником.

После каждых восьми жестов программа проверяет полный снимок. Перед обработкой блока `g`, начиная с нуля, его восемь байтов раскрываются из начального состояния этого блока:

```python
x, y, f, e, a = state
key = (a ^ (e << 24) ^ (x << 16) ^ (y << 8) ^ f
       ^ 0xa53c19e7 ^ ((g*0x6d2b79f5) & MASK))
raw = bytearray()
for b in data[84+8*g:92+8*g]:
    key = xs(key)
    raw.append(b ^ (key & 255))
target = struct.unpack('<4BI', raw)
```

Перебирать все 40 жестов сразу дорого: это `4^40` вариантов. Но начальное состояние первого блока известно из заголовка, а его целевое состояние уже можно расшифровать. Перебираем только `4^8 = 65536` последовательностей и сравниваем все пять полей. Найденный снимок становится стартом следующего блока.

Солв перебирает каждый блок полностью, чтобы проверить уникальность, а не останавливается на первом совпадении:

```python
def visit(state, depth, word):
    if depth == 8:
        if state == target:
            found.append(word)
        return
    for c in range(4):
        visit(step(state, c, g*8+depth, board),
              depth+1, word + 'wasd'[c])
```

Для текущей выдачи каждый из пяти блоков даёт ровно одного кандидата. Полученные жесты группируем по четыре и собираем байт формулой `value = (value << 2) | c`. Так восстанавливается тело флага; остаётся добавить `vka{` и `}`.
