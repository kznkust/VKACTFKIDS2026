# Reversi

| Событие | Название | Категория | Сложность |
| :-----: | :------: | :-------: | :-------: |
| VKACTF Kids 2026 | Reversi | Reverse | Medium |

  
### Описание

>
Нашел класнную игру, но донат временно недоступен, а я очень сильно хотел vip, сможешь помочь?

### Решение

1. Запустить игру, сыграть партию, найти сохранение (`strings` → `/.reversi`, `profile.sav`,
   или `strace -e openat`).
2. Увидеть в `sign` формат `$6$…$…` → SHA-512 crypt. Поправить `vip=1000` в лоб не выйдет:
   игра заметит подмену.
3. В Ghidra/IDA найти вызов `crypt_r`: перед ним `snprintf` с форматом
   `%s|%s|%ld|%ld|%ld|%ld|%ld`, первый `%s` — буфер после цикла
   `buf[i] = blob[i] ^ (0x37 + 13*i)` по 16 байтам из `.rodata`. Расшифровать → `9fT#q2Lx!vR8@mZ1`.
   Восстановить порядок аргументов: `KEY, name, vip, coins, wins, losses, draws`.
4. Пересчитать подпись стандартной утилитой:
   ```bash
   openssl passwd -6 -salt <соль_из_файла> '9fT#q2Lx!vR8@mZ1|alice|1000|105|0|1|0'
   ```
   и записать в файл вместе с `vip=1000` (или запустить `solution/solve.py`).
5. Запустить игру → «VIP-зал» → сервер проверяет подпись и присылает флаг.

### Флаг
```
vka{v1p_st4tus_1s_4_n0_s4lt_n0_pr0bl3m}
```
