# Palimpsest

| Событие | Название | Категория | Сложность |
| :-----: | :------: | :-------: | :-------: |
| VKACTF Kids 2026 | Palimpsest | Web | Hard |

### Решение

В ведомости 78 меток. По четырём цехам распределены 208 проб для 26 листов. Из каждой пробы нужно получить квитанцию кнопки «В реестр».

**Получение квитанций**

Берём три значения поля `mark` в порядке отправки. Учитываем поля, привязанные к форме через атрибут `form`, и значение кнопки, которой отправлена форма. В отключённом `fieldset` участвуют поля внутри первого `legend`. Неотмеченные радиокнопки и опции отключённого `optgroup` пропускаются.

```js
const button = form.querySelector('button[data-edition="register"]');
const marks = new FormData(form, button).getAll("mark");
```

**Сборка тиража**

В матрице точного покрытия 104 столбца. По одному столбцу на каждый из 26 листов и на каждую из 78 меток. Каждая квитанция покрывает четыре столбца, свой лист и три метки. Алгоритмом X выбираем пробы так, чтобы каждый столбец оказался покрыт ровно один раз.

Упорядочиваем пробы по номеру листа от `01` до `26`. Для каждого листа пишем номер, идентификатор пробы и три метки в порядке квитанции через один пробел. Каждая строка заканчивается LF. Сдаём SHA-256 ASCII-байтов реестра в нижнем hex.
