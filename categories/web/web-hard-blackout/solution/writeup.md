# Blackout

| Событие | Название | Категория | Сложность |
| :-----: | :------: | :-------: | :-------: |
| VKACTF Kids 2026 | Blackout | Web | Hard |

### Решение

У каждого буя есть две редакции, `en` и `fr`. С полевого талона берём адрес первой записи и опорную ячейку.

**Паспорта буёв**

1. Запросом `HEAD` с нужным `Accept-Language` получаем `ETag` редакции.
2. Запросом `GET` с тем же языком и тегом в `If-None-Match` получаем `304`. В заголовках указаны соседний буй, сдвиг и два диапазона байтов.
3. Читаем обе части запросами с `Range` и `If-Range`. Склеиваем их в порядке паспорта.
4. Обходим ссылки обеих редакций. Получаем 17 буёв и 34 связи.

**Восстановление лент**

Для связи из `v` в `w` выполняется `S[v] = R_s(S[w]) ⊕ D`, где `R_s` циклически сдвигает ленту на `s` ячеек, а `D` получена из двух диапазонов. При обходе выражаем каждую ленту через опорную ленту `A` в виде `R_p(A) ⊕ M`.

Если два пути дают для одной ленты параметры `(p, M)` и `(q, N)`, получаем `A = R_(q-p)(A) ⊕ R_-p(M ⊕ N)`. Берём замыкание с ненулевым сдвигом. Такой сдвиг обходит все 13 ячеек, поэтому известное значение одной ячейки восстанавливает остальные. По опорной ленте вычисляем ленты всех буёв.

Склеиваем ленты по возрастанию номера буя и сдаём SHA-256 полученных байтов в нижнем hex.
