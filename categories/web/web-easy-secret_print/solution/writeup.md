# Типография

| Событие | Название | Категория | Сложность |
| :-----: | :------: | :-------: | :-------: |
| VKACTF Kids 2026 | Типография | Web | Easy |

### Решение

1. Открываем главную страницу и смотрим список карточек. У запечатанного конверта номер **117**.
2. Запрос `GET /api/card/117` возвращает **403** — основной API корректно проверяет доступ.
3. Кнопка «Печатать выпуск» открывает `GET /api/print?ids=101%2C105%2C109%2C113`. Параметр `ids` — перечисление номеров, которым клиент управляет сам.
4. Меняем запрос на `GET /api/print?ids=117` (можно просто открыть URL в браузере).
5. Печатный маршрут собирает карточки без проверки приватности и выдаёт `vka{print_queue_forgot_the_lock}`.
