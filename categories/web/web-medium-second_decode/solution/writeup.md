# Мастерская красной печати

| Событие | Название | Категория | Сложность |
| :-----: | :------: | :-------: | :-------: |
| VKACTF Kids 2026 | Мастерская красной печати | Web | Medium |

### Решение

1. Выдаём оттиск для `public/artboard.txt`, открываем заверенную копию. Там есть имя интересующего файла: `staff/final_note.txt`.
2. Форма подписи принимает имя пути. Простой `staff/final_note.txt` не проходит проверку `public/`.
3. Прямой `public/../staff/final_note.txt` тоже отклоняется: проверка запрещает `..`.
4. Зато имя `public/%2e%2e/staff/final_note.txt` **не содержит двух буквальных точек**. В форму вводим именно такую строку. Интерфейс при отправке дополнительно URL-кодирует `%` в `%25`.
5. `/api/stamp` подписывает исходную строку `public/%2e%2e/staff/final_note.txt`. В полученной ссылке `/file?file=...&stamp=...` подпись уже корректная — подделывать криптографию не нужно.
6. `/file` проверяет подпись, затем делает **дополнительное** `unquote(file)`. Имя меняется на `public/../staff/final_note.txt`; нормализация файловой системы приводит к `data/staff/final_note.txt`. Получаем `vka{signed_before_the_second_decode}`.
