# VoidCustoms

| Событие | Название | Категория | Сложность |
| :-----: | :------: | :-------: | :-------: |
| VKACTF Kids 2026 | VoidCustoms | Misc | Hard |

### Решение

Получаем экспорт `VCT2`. Формат записей и направления съёмки берём из паспорта, координаты контрольных точек берём из `calibration.csv`.

**Определение ориентации**

Разбираем записи по их ширине и высоте. Разворачиваем обе полосы в нечётных строках и вычитаем тёмное значение. Потерянные замеры сохраняем как отсутствующие. Для каждого направления проецируем контрольные точки на сетку детектора. Перебираем допустимые повороты и отражения контрольной полосы. Совпадение определяет положение детектора и список вокселей на каждом луче.

**Восстановление объёма**

Каждый сохранившийся замер задаёт число заполненных вокселей на луче. Храним остаток этой суммы и число ещё неизвестных вокселей. Когда остаток равен нулю, все неизвестные воксели на луче пустые. Когда он равен числу неизвестных, все они заполнены. После каждого присвоения обновляем пересекающие лучи до восстановления всех 4096 вокселей.

Обходим пустые воксели по шести соседям. Компоненты, достигающие края куба, считаем внешними. Для трёх крупнейших закрытых полостей записываем минимальные координаты и размеры по формату паспорта. Первой строкой декларации сдаём SHA-256 сырых байтов объёма, затем три строки полостей.

Солв представлен в файле [solution.py](solution.py)
