# Слепой дилер

| Событие | Название | Категория | Сложность |
| :-----: | :------: | :-------: | :-------: |
| VKACTF Kids 2026 | Слепой дилер | Misc | Easy |

### Решение

Сервис показывает три тренировочные колоды из 16 карт. Для получения флага нужно десять раз подряд назвать первые пять карт следующей колоды в правильном порядке.

**Обращение тасовки**

Тасовка кодирует состояние LCG в перестановку 16 карт. Остатки от деления
на `16, 15, ..., 1` задают индексы карт в списке ещё не выбранных.
Поскольку `16! > 2^31 - 1`, состояние помещается в колоду без потерь.

Для каждой карты найдите её индекс в оставшихся картах и прибавьте его
с весом `1, 16, 16*15, ...`. Так восстанавливаются три состояния `x1, x2, x3`
из поля `practice`, полученного через `POST /api/new`.

**Восстановление генератора**

Модуль известен: `p = 2^31 - 1`. Вычисляем:

```text
a = (x3 - x2) * inverse(x2 - x1, p) mod p
c = (x2 - a*x1) mod p
```

Сервер исключает неподвижную точку, а множитель ненулевой. Поэтому соседние
состояния различны и обратный элемент существует при каждой игре.

**Предсказание раздач**

Десять раз обновляем `state = (a*state + c) mod p`, выполняем тасовку
и отправляем первые пять карт в `POST /api/guess` с текущим номером раунда.
Cookie, полученную при создании стола, сохраняем во всех запросах.
При сетевой задержке солвер делает до 20 попыток с интервалом 800 мс
(при немедленной сетевой ошибке следующая попытка начинается сразу).
Создание стола повторяется с одним `request_id`; если ответ на ход потерян,
сначала читается `/api/state`, чтобы восстановить уже выполненный ход.
Конфликт номера раунда также обрабатывается чтением состояния.
Это позволяет продолжить игру, не применяя один ход дважды.

Солв представлен в файле [solve.py](solve.py).
