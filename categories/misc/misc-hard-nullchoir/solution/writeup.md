# NullChoir

| Событие | Название | Категория | Сложность |
| :-----: | :------: | :-------: | :-------: |
| VKACTF Kids 2026 | NullChoir | Misc | Hard |

### Решение

Из карточки сеанса получаем стереозапись и нужный позывной. Параметры передачи берём из паспорта и профиля станции.

**Выделение посылок**

Для задержек от 2 до 11 отсчётов считаем нормированную корреляцию между `L[:-d]` и `R[d:]`. По максимуму находим задержку `d`, затем оцениваем усиление `g = (L·R)/(L·L)` на выровненных каналах. Рабочий сигнал получаем как `R[d:] - g L[:-d]`.

Начала посылок находим по корреляции с пилотом. На окнах по 64 отсчёта измеряем комплексную амплитуду несущей 1750 Гц. По разности фаз соседних окон восстанавливаем четверти оборота и переводим их в пары битов по таблице `dibit_to_turn`. Оставляем кадры с верной CRC и нужным позывным.

**Восстановление сообщения**

Каждый исправный кадр задаёт значение `x` и шесть показаний. Строим строки `1, x, x², …, x⁷` по модулю 257. Восемь кадров с разными `x` определяют коэффициенты шести полиномов. Решаем систему исключением Гаусса по модулю 257 и сверяем по девятому кадру. Склеиваем коэффициенты по строкам и сдаём 48 байтов в нижнем hex.

Для запуска скрипта нужен NumPy.

Солв представлен в файле [solution.py](solution.py)
