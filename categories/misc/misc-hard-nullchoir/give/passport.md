# Радиоузел «Полынья». Паспорт аварийного тракта PLN-6

## Магнитофон

WAV хранит два канала PCM16. На левый подан контрольный звук. На правый попадает копия того же сигнала с постоянным усилением и задержкой 2–11 отсчётов. Служебная посылка записана поверх правого канала. В перерывах между посылками контрольный тон продолжается. Положение первой посылки с сеткой символов всего файла не связано. Между посылками интервалы произвольной длины.

## Посылка

Несущая делает `carrier_bin` полных циклов за `symbol_samples` отсчётов. Символ занимает ровно такой блок. Первая фаза в каждой посылке произвольна. За ней идут фазовые переходы из `pilot_turns` (единица равна четверти оборота вперёд), затем данные в той же разностной модуляции. `dibit_to_turn` индексируется значениями двух битов 0…3. Байты собираются от старшей пары битов к младшей.

При частоте дискретизации 16000 Гц семь циклов за 64 отсчёта дают 1750 Гц. Одна посылка занимает `(1 + длина пилота + 4 × 17) × 64` отсчётов.

## Кадр из 17 байтов

| Смещение | Длина | Поле |
|---|---:|---|
| 0 | 2 | Позывной в порядке передачи |
| 2 | 1 | Координата замера x от 1 до 255 |
| 3 | 12 | Шесть показаний y, uint16 big-endian |
| 15 | 2 | CRC-16/CCITT-FALSE по первым 15 байтам, big-endian |

CRC использует полином `0x1021`, начальное значение `0xffff`, без отражения и финального XOR. Для байтов ASCII `123456789` значение равно `0x29b1`. В одной ленте могут быть исправные кадры других позывных и кадры с повреждённой контрольной суммой.

## Таблица изъятых данных

Передатчик разбивает исходное сообщение на восемь строк по шесть байтов. Каждый столбец становится полиномом степени не выше 7 в поле по модулю 257. Первая строка — свободный член, вторая — коэффициент при x, и так далее. Исправный кадр сообщает значения всех шести полиномов при одном x. Для отчёта склейте строки с первой по восьмую и запишите все 48 байтов в нижнем hex.
