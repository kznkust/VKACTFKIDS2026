# ДНСтаграм

| Событие | Название | Категория | Сложность |
| :-----: | :------: | :-------: | :-------: |
| VKACTF Kids 2026 | ДНСтаграм | Forensics | Medium |

### Решение

1. В заметке `shift_log.txt` найдём IP проектора `10.26.2.17`. Отфильтруем его DNS-запросы в Wireshark: `ip.src == 10.26.2.17 && dns`.
2. Среди имён видны запросы вида `p003-<BASE32>.s7.snapboard.invalid`. Первый фрагмент `p003` — порядковый номер, длинная часть выглядит как Base32 (`A-Z`, `2-7`). Домен `s7.snapboard.invalid` — сеанс проектора.
3. Извлечём **первую метку имени** каждого такого DNS-запроса. Игнорируем `s8`, которые относятся к компьютеру библиотеки, и одинаковые повторные `pNNN`.
4. Сортируем по числу `NNN`, отдельно декодируем Base32 **каждого фрагмента**, склеиваем полученные бинарные кусочки.
5. Первые байты итоговой строки `1f 8b` указывают на gzip. Распаковываем: получился SVG. Открываем его браузером/просмотрщиком.
6. На слайде видно `vka{the_last_slide_was_in_dns}`.
